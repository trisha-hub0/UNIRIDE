# UniRide 🚗

**UniRide** is a frontend prototype of a campus carpooling platform designed for GAT students and staff. It aims to help students and staff connect and share rides within their campus community.

🌐 **Live Demo:** [https://uniride-nine.vercel.app/login.html](https://uniride-nine.vercel.app/login.html)

## 📌 Project Overview

UniRide is a web development project that demonstrates the user interface and design of a campus ride-sharing platform. It provides a prototype experience for users to explore ride-related features and user profile interfaces.

This project is currently a **frontend-only prototype** and does not have a backend server or database.

## ✨ Features

- Login and user interface
- Campus-specific email validation
- User profile interface
- Ride search interface
- Post a ride interface
- My rides interface
- Browser-based data storage for demo purposes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Vercel (Deployment)

## ⚠️ Project Status

UniRide is currently a **frontend prototype developed for demonstration purposes**.

- No backend integration
- No database
- Demo data is stored in browser localStorage
- No real ride booking or ride matching system

## 🎯 Objective

The objective of UniRide is to explore and demonstrate the design of a campus-based carpooling platform that encourages convenient ride-sharing among students and staff.
